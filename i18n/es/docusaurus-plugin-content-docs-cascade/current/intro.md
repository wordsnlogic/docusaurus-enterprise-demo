# Introducción

Bienvenido a la documentación de Cascade.

Cascade es una de las líneas de producto de la plataforma Northwind Cloud.

## Características principales

- Declarative pipeline definitions in YAML
- Built-in connectors for 40+ data sources
- Automatic schema drift detection

## Qué encontrarás aquí

Esta sección cubre la instalación, la configuración y los conceptos clave para integrarte con este producto.
