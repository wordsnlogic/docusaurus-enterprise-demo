# Introducción

Bienvenido a la documentación de Falcon.

Falcon es una de las líneas de producto de la plataforma Northwind Cloud.

## Características principales

- Hybrid keyword + vector ranking
- Typo-tolerant fuzzy matching
- Sub-100ms query latency at 10M+ documents

Esta sección cubre la instalación, la configuración y los conceptos clave para integrarte con este producto.
