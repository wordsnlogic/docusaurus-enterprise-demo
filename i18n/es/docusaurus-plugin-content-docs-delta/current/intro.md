# Introducción

Bienvenido a la documentación de Delta.

Delta es una de las líneas de producto de la plataforma Northwind Cloud.

## Características principales

- Bi-directional sync with conflict resolution
- Sub-second propagation between endpoints
- Change-data-capture from Postgres, MySQL, and Mongo

## Qué encontrarás aquí

Esta sección cubre la instalación, la configuración y los conceptos clave para integrarte con este producto.
