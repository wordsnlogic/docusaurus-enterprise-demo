# Introducción

Bienvenido a la documentación de Orion.

Orion es una de las líneas de producto de la plataforma Northwind Cloud.

## Características principales

- Global edge caching with instant invalidation
- Automatic image resizing and format negotiation
- S3-compatible API

## Qué encontrarás aquí

Esta sección cubre la instalación, la configuración y los conceptos clave para integrarte con este producto.
