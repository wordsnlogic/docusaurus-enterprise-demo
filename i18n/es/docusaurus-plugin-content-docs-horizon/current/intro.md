# Introducción

Bienvenido a la documentación de Horizon.

Horizon es una de las líneas de producto de la plataforma Northwind Cloud.

## Características principales

- Drag-and-drop dashboard builder
- Row-level data security per embed
- White-labeled embeds via signed tokens

## Qué encontrarás aquí

Esta sección cubre la instalación, la configuración y los conceptos clave para integrarte con este producto.
