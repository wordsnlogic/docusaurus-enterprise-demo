# Referencia de la API

## Autenticación

Todas las solicitudes a la API de Lumen deben incluir un token de portador válido en el encabezado Authorization.

## Endpoints

La siguiente tabla enumera los principales endpoints expuestos por la API de Lumen.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/lumen/messages` | Send a transactional message |
| GET | `/v1/lumen/messages/:id` | Check delivery status |
| POST | `/v1/lumen/templates` | Create a message template |
