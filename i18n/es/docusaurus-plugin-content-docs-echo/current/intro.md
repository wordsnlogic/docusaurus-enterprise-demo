# Introducción

Bienvenido a la documentación de Echo.

Echo es una de las líneas de producto de la plataforma Northwind Cloud.

## Características principales

- Drop-in chat UI components for web and mobile
- End-to-end encrypted channels
- Webhooks for every message and presence event

## Qué encontrarás aquí

Esta sección cubre la instalación, la configuración y los conceptos clave para integrarte con este producto.
