# Referencia de la API

## Autenticación

Todas las solicitudes a la API de Beacon deben incluir un token de portador válido en el encabezado Authorization.

## Endpoints

La siguiente tabla enumera los principales endpoints expuestos por la API de Beacon.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/beacon/monitors` | Create a new uptime monitor |
| GET | `/v1/beacon/incidents` | List open and resolved incidents |
| POST | `/v1/beacon/status-pages` | Publish a public status page |
