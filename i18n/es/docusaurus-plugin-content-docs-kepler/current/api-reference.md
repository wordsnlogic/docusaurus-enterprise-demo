# Referencia de la API

## Autenticación

Todas las solicitudes a la API de Kepler deben incluir un token de portador válido en el encabezado Authorization.

## Endpoints

La siguiente tabla enumera los principales endpoints expuestos por la API de Kepler.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/kepler/geocode` | Convert an address to coordinates |
| POST | `/v1/kepler/routes` | Calculate a route between points |
| POST | `/v1/kepler/geofences` | Create a geofence |
