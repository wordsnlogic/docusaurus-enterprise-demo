# Introducción

Bienvenido a la documentación de Kepler.

Kepler es una de las líneas de producto de la plataforma Northwind Cloud.

## Características principales

- Turn-by-turn routing and ETAs
- Reverse geocoding at street-level accuracy
- Geofencing with real-time enter/exit events

## Qué encontrarás aquí

Esta sección cubre la instalación, la configuración y los conceptos clave para integrarte con este producto.
