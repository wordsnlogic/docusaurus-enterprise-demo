# Introducción

Bienvenido a la documentación de Juno.

Juno es una de las líneas de producto de la plataforma Northwind Cloud.

## Características principales

- Cron and event-triggered jobs
- At-least-once and exactly-once delivery modes
- Automatic retries with exponential backoff

## Qué encontrarás aquí

Esta sección cubre la instalación, la configuración y los conceptos clave para integrarte con este producto.
