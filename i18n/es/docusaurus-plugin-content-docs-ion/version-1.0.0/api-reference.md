# Referencia de la API

## Autenticación

Todas las solicitudes a la API de Ion deben incluir un token de portador válido en el encabezado Authorization.

## Endpoints

La siguiente tabla enumera los principales endpoints expuestos por la API de Ion.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/ion/charges` | Create a one-time charge |
| POST | `/v1/ion/subscriptions` | Create a subscription |
| POST | `/v1/ion/refunds` | Issue a refund |
