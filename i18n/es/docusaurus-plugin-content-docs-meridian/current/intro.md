# Introducción

Bienvenido a la documentación de Meridian.

Meridian es una de las líneas de producto de la plataforma Northwind Cloud.

## Características principales

- Visual workflow builder with branching logic
- 200+ pre-built integration steps
- Human-in-the-loop approval steps
