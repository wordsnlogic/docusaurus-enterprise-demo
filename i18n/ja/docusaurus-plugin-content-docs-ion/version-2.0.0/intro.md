# はじめに

Ion は Northwind Cloud の決済 API です。135以上の通貨での Charge、保存済み支払い方法、
サブスクリプション、返金に対応し、PCI-DSS レベル1準拠のカード保管により生のカード番号がサーバーに
触れることはありません。

## テストモードとライブモード

すべての Ion アカウントにはテスト用（`sk_test_`）とライブ用（`sk_live_`）の別々のキーがあります。
テストモードはライブモードと同じ検証ロジックを使用しますが、実際の資金は動きません——キーを
切り替える前に、失敗パスも含めて統合全体をテストモードで検証してください。

## 主な機能

- 135以上の通貨とローカル決済手段
- PCI-DSS レベル1準拠のカード保管——カード番号はサーバーに触れません
- 従量課金とサブスクリプション課金、失敗時の自動督促

## はじめる前に

Charge 作成のコードを書く前に、[コンセプト](./concepts.md)で金額が整数として表現される理由と
冪等キーの仕組みを読んでください。どちらも一度間違えやすく、本番環境での修正コストが高い部分です。
