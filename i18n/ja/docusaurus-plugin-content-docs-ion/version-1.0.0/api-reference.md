# API リファレンス

## 認証

Ion API へのすべてのリクエストには、Authorization ヘッダーに有効なベアラートークンを含める必要があります。

## エンドポイント

以下の表は、Ion API が提供する主なエンドポイントの一覧です。

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/ion/charges` | Create a one-time charge |
| POST | `/v1/ion/subscriptions` | Create a subscription |
| POST | `/v1/ion/refunds` | Issue a refund |

## サポート

Ion に関するご質問は、製品チームまでご連絡いただくか、コミュニティフォーラムをご覧ください。
