# API リファレンス

## 認証

Ion API へのすべてのリクエストには、Authorization ヘッダーに有効なベアラートークンを含める必要があります。

## エンドポイント

以下の表は、Ion API が提供する主なエンドポイントの一覧です。

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/ion/status` | Health/status check |
| GET | `/v1/ion/resources` | List resources |
| POST | `/v1/ion/resources` | Create a resource |
| DELETE | `/v1/ion/resources/:id` | Delete a resource |

## サポート

Ion に関するご質問は、製品チームまでご連絡いただくか、コミュニティフォーラムをご覧ください。
