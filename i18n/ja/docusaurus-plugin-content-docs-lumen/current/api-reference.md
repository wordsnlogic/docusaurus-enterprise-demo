# API リファレンス

## 認証

Lumen API へのすべてのリクエストには、Authorization ヘッダーに有効なベアラートークンを含める必要があります。

## エンドポイント

以下の表は、Lumen API が提供する主なエンドポイントの一覧です。

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/lumen/messages` | Send a transactional message |
| GET | `/v1/lumen/messages/:id` | Check delivery status |
| POST | `/v1/lumen/templates` | Create a message template |

## サポート

Lumen に関するご質問は、製品チームまでご連絡いただくか、コミュニティフォーラムをご覧ください。
