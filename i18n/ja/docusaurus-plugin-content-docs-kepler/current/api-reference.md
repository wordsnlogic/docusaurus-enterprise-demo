# API リファレンス

## 認証

Kepler API へのすべてのリクエストには、Authorization ヘッダーに有効なベアラートークンを含める必要があります。

## エンドポイント

以下の表は、Kepler API が提供する主なエンドポイントの一覧です。

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/kepler/geocode` | Convert an address to coordinates |
| POST | `/v1/kepler/routes` | Calculate a route between points |
| POST | `/v1/kepler/geofences` | Create a geofence |

## サポート

Kepler に関するご質問は、製品チームまでご連絡いただくか、コミュニティフォーラムをご覧ください。
