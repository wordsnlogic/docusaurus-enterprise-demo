# はじめに

Kepler のドキュメントへようこそ。

Kepler は Northwind Cloud プラットフォームの製品ラインのひとつです。

## 主な機能

- Turn-by-turn routing and ETAs
- Reverse geocoding at street-level accuracy
- Geofencing with real-time enter/exit events
