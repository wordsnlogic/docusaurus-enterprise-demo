# API リファレンス

## 認証

Genesis API へのすべてのリクエストには、Authorization ヘッダーに有効なベアラートークンを含める必要があります。

## エンドポイント

以下の表は、Genesis API が提供する主なエンドポイントの一覧です。

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/genesis/users` | Create a user |
| POST | `/v1/genesis/sessions` | Start an authenticated session |
| POST | `/v1/genesis/sso/connections` | Configure an enterprise SSO connection |

## サポート

Genesis に関するご質問は、製品チームまでご連絡いただくか、コミュニティフォーラムをご覧ください。
