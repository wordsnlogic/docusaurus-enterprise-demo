# はじめに

Genesis のドキュメントへようこそ。

Genesis は Northwind Cloud プラットフォームの製品ラインのひとつです。

## 主な機能

- SAML and OIDC SSO out of the box
- Passwordless magic-link and passkey login
- Fine-grained role-based access control
