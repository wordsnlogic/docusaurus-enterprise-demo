# 소개

Genesis 문서에 오신 것을 환영합니다.

Genesis는 Northwind Cloud 플랫폼의 제품 라인 중 하나입니다.

## 주요 기능

- SAML and OIDC SSO out of the box
- Passwordless magic-link and passkey login
- Fine-grained role-based access control

## 이 문서에서 다루는 내용

이 섹션에서는 설치, 구성, 그리고 이 제품과 연동하기 위해 필요한 핵심 개념을 다룹니다.
