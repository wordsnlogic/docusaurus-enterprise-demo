# 개념

Atlas에는 네 가지 핵심 객체가 있습니다.

## 이벤트

**이벤트**는 사용자가 수행한 동작에 대한 타임스탬프가 있는 단일 사실입니다 (`checkout_completed`,
`page_viewed`). 필드: `name`(일관된 명명 규칙을 사용하세요 — 그렇지 않으면 퍼널이 조용히 깨집니다),
`user_id`, `timestamp`(백필의 경우 최대 24시간 전까지 허용), `properties`(자유 형식 JSON 객체). 이벤트는
수집 후 불변입니다 — 수정 API는 없으며, 잘못 보냈다면 수정된 이벤트를 다시 보내세요.

## 아이덴티티

Atlas는 `user_id`(직접 관리하는 문자열)로 사용자를 추적합니다. 익명 방문자가 나중에 로그인하는 경우
과거 이벤트를 새 ID로 다시 보내지 말고 [시작하기](./getting-started.md)의 아이덴티티
병합 기능을 사용하세요.

## 퍼널

**퍼널**은 이벤트 이름의 순서 있는 시퀀스입니다. Atlas는 각 단계를 완료한 아이덴티티 수와 이탈 지점을
계산합니다. 한 번 정의하고(`POST /v1/atlas/funnels`) 반복적으로 조회합니다(`GET
/v1/atlas/funnels/:id`).

## 코호트

**코호트**는 저장된 정의입니다("최근 30일 내 가입"). 조회할 때마다 다시 계산되며, 생성 시점의 고정된
스냅샷이 아닙니다.
