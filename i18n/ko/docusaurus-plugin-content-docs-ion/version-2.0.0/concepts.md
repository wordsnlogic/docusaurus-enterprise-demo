# 개념

## 금액은 정수입니다

Ion의 모든 금액은 통화의 최소 단위 정수입니다 — USD는 센트, JPY는 보조 단위가 없어 ¥500은 `500`입니다.
`amount: 4200`과 `currency: "usd"`는 $42.00을 의미합니다.

## 청구(Charge)

**청구**는 고객에게서 자금을 이동시키는 단일 시도입니다. 생성은 한 번에 이루어지고 정산은
비동기적으로 진행됩니다 — `succeeded`는 승인되었다는 의미이며 정산 완료를 보장하지는 않습니다.

## 고객과 결제 수단

**고객**은 하나 이상의 **결제 수단**을 연결할 수 있는 재사용 가능한 레코드입니다. 매번 카드 정보를
전달하는 대신 고객을 먼저 생성하면 저장된 카드 결제와 구독이 가능해집니다.

## 멱등성 키

모든 쓰기 엔드포인트는 `idempotency_key`를 받습니다. 요청이 타임아웃된 후 동일한 키로 재시도하면
중복 청구 대신 원래 결과를 반환합니다. 동일 키에 다른 요청 본문을 사용하면 오류입니다([오류](./api-reference.md)
참고). 키는 무작위가 아닌 주문 ID처럼 안정적인 값에 연결하세요.

## 구독

**구독**은 고객을 요금제에 연결하고 정기적으로 청구합니다. `current_period_end`가 있으며, 결제
실패 시 즉시 취소되지 않고 `past_due`로 전환되어 유예 기간을 제공합니다.

## 환불

환불은 청구를 참조하며 부분 환불이 가능합니다. 누적 환불 금액이 원 금액을 초과하지 않는 한 여러 번
가능합니다.
