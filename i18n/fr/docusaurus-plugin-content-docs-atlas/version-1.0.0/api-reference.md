# Référence API

## Authentification

Toutes les requêtes vers l'API Atlas doivent inclure un jeton porteur valide dans l'en-tête Authorization.

## Points de terminaison

Le tableau ci-dessous liste les principaux points de terminaison exposés par l'API Atlas.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/atlas/status` | Health/status check |
| GET | `/v1/atlas/resources` | List resources |
| POST | `/v1/atlas/resources` | Create a resource |
| DELETE | `/v1/atlas/resources/:id` | Delete a resource |

## Assistance

Pour toute question sur Atlas, contactez l'équipe produit ou consultez le forum communautaire.
