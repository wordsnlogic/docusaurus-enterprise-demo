# Référence API

## Authentification

Toutes les requêtes vers l'API Atlas doivent inclure un jeton porteur valide dans l'en-tête Authorization.

## Points de terminaison

Le tableau ci-dessous liste les principaux points de terminaison exposés par l'API Atlas.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/atlas/events` | Ingest a batch of analytics events |
| GET | `/v1/atlas/funnels/:id` | Retrieve funnel conversion data |
| GET | `/v1/atlas/cohorts/:id` | Retrieve a retention cohort |
