# Introduction

Bienvenue dans la documentation de Delta.

Delta est l'une des gammes de produits de la plateforme Northwind Cloud.

## Fonctionnalités clés

- Bi-directional sync with conflict resolution
- Sub-second propagation between endpoints
- Change-data-capture from Postgres, MySQL, and Mongo

## Contenu de cette section

Cette section couvre l'installation, la configuration et les concepts essentiels pour intégrer ce produit.
