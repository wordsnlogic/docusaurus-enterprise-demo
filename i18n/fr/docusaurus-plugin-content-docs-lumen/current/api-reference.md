# Référence API

## Authentification

Toutes les requêtes vers l'API Lumen doivent inclure un jeton porteur valide dans l'en-tête Authorization.

## Points de terminaison

Le tableau ci-dessous liste les principaux points de terminaison exposés par l'API Lumen.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/lumen/messages` | Send a transactional message |
| GET | `/v1/lumen/messages/:id` | Check delivery status |
| POST | `/v1/lumen/templates` | Create a message template |
