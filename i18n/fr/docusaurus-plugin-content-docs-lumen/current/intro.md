# Introduction

Bienvenue dans la documentation de Lumen.

Lumen est l'une des gammes de produits de la plateforme Northwind Cloud.

## Fonctionnalités clés

- Multi-channel delivery from one API
- Built-in deliverability and bounce handling
- Template management with versioning

## Contenu de cette section

Cette section couvre l'installation, la configuration et les concepts essentiels pour intégrer ce produit.
