# Introduction

Bienvenue dans la documentation de Cascade.

Cascade est l'une des gammes de produits de la plateforme Northwind Cloud.

## Fonctionnalités clés

- Declarative pipeline definitions in YAML
- Built-in connectors for 40+ data sources
- Automatic schema drift detection

## Contenu de cette section

Cette section couvre l'installation, la configuration et les concepts essentiels pour intégrer ce produit.
