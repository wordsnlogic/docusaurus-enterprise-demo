# Référence API

## Authentification

Toutes les requêtes vers l'API Kepler doivent inclure un jeton porteur valide dans l'en-tête Authorization.

## Points de terminaison

Le tableau ci-dessous liste les principaux points de terminaison exposés par l'API Kepler.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/kepler/geocode` | Convert an address to coordinates |
| POST | `/v1/kepler/routes` | Calculate a route between points |
| POST | `/v1/kepler/geofences` | Create a geofence |

## Assistance

Pour toute question sur Kepler, contactez l'équipe produit ou consultez le forum communautaire.
