# Introduction

Bienvenue dans la documentation de Nova.

Nova est l'une des gammes de produits de la plateforme Northwind Cloud.

## Fonctionnalités clés

- One-command deploy from common ML frameworks
- Auto-scaling GPU inference endpoints
- Built-in request/response logging for drift detection

## Contenu de cette section

Cette section couvre l'installation, la configuration et les concepts essentiels pour intégrer ce produit.
