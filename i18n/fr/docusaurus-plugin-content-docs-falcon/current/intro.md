# Introduction

Bienvenue dans la documentation de Falcon.

Falcon est l'une des gammes de produits de la plateforme Northwind Cloud.

## Fonctionnalités clés

- Hybrid keyword + vector ranking
- Typo-tolerant fuzzy matching
- Sub-100ms query latency at 10M+ documents

## Contenu de cette section

Cette section couvre l'installation, la configuration et les concepts essentiels pour intégrer ce produit.
