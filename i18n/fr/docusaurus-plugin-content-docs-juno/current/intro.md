# Introduction

Bienvenue dans la documentation de Juno.

Juno est l'une des gammes de produits de la plateforme Northwind Cloud.

## Fonctionnalités clés

- Cron and event-triggered jobs
- At-least-once and exactly-once delivery modes
- Automatic retries with exponential backoff

## Contenu de cette section

Cette section couvre l'installation, la configuration et les concepts essentiels pour intégrer ce produit.
