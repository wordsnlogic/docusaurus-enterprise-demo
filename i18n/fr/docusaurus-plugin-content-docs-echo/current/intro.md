# Introduction

Bienvenue dans la documentation de Echo.

Echo est l'une des gammes de produits de la plateforme Northwind Cloud.

## Fonctionnalités clés

- Drop-in chat UI components for web and mobile
- End-to-end encrypted channels
- Webhooks for every message and presence event

## Contenu de cette section

Cette section couvre l'installation, la configuration et les concepts essentiels pour intégrer ce produit.
