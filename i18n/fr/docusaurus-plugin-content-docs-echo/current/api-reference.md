# Référence API

## Authentification

Toutes les requêtes vers l'API Echo doivent inclure un jeton porteur valide dans l'en-tête Authorization.

## Points de terminaison

Le tableau ci-dessous liste les principaux points de terminaison exposés par l'API Echo.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/echo/channels` | Create a chat channel |
| POST | `/v1/echo/messages` | Send a message to a channel |
| GET | `/v1/echo/channels/:id/messages` | Fetch channel message history |

## Assistance
