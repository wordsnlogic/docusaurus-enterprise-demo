# Introduction

Bienvenue dans la documentation de Orion.

Orion est l'une des gammes de produits de la plateforme Northwind Cloud.

## Fonctionnalités clés

- Global edge caching with instant invalidation
- Automatic image resizing and format negotiation
- S3-compatible API

## Contenu de cette section

Cette section couvre l'installation, la configuration et les concepts essentiels pour intégrer ce produit.
