# Référence API

## Authentification

Toutes les requêtes vers l'API Ion doivent inclure un jeton porteur valide dans l'en-tête Authorization.

## Points de terminaison

Le tableau ci-dessous liste les principaux points de terminaison exposés par l'API Ion.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/ion/charges` | Create a one-time charge |
| POST | `/v1/ion/subscriptions` | Create a subscription |
| POST | `/v1/ion/refunds` | Issue a refund |

## Assistance

Pour toute question sur Ion, contactez l'équipe produit ou consultez le forum communautaire.
