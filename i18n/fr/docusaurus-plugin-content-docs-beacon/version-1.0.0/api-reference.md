# Référence API

## Authentification

Toutes les requêtes vers l'API Beacon doivent inclure un jeton porteur valide dans l'en-tête Authorization.

## Points de terminaison

Le tableau ci-dessous liste les principaux points de terminaison exposés par l'API Beacon.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/beacon/status` | Health/status check |
| GET | `/v1/beacon/resources` | List resources |
| POST | `/v1/beacon/resources` | Create a resource |
| DELETE | `/v1/beacon/resources/:id` | Delete a resource |
