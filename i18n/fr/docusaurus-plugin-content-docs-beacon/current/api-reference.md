# Référence API

## Authentification

Toutes les requêtes vers l'API Beacon doivent inclure un jeton porteur valide dans l'en-tête Authorization.

## Points de terminaison

Le tableau ci-dessous liste les principaux points de terminaison exposés par l'API Beacon.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/beacon/monitors` | Create a new uptime monitor |
| GET | `/v1/beacon/incidents` | List open and resolved incidents |
| POST | `/v1/beacon/status-pages` | Publish a public status page |

## Assistance

Pour toute question sur Beacon, contactez l'équipe produit ou consultez le forum communautaire.
