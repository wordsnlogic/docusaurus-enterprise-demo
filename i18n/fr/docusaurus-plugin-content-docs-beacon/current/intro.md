# Introduction

Bienvenue dans la documentation de Beacon.

Beacon est l'une des gammes de produits de la plateforme Northwind Cloud.

## Fonctionnalités clés

- Multi-region synthetic checks every 30 seconds
- Alert routing to Slack, PagerDuty, and email
- Public, brandable status pages per customer

## Contenu de cette section

Cette section couvre l'installation, la configuration et les concepts essentiels pour intégrer ce produit.
