# Introduction

Bienvenue dans la documentation de Genesis.

Genesis est l'une des gammes de produits de la plateforme Northwind Cloud.

## Fonctionnalités clés

- SAML and OIDC SSO out of the box
- Passwordless magic-link and passkey login
- Fine-grained role-based access control

## Contenu de cette section

Cette section couvre l'installation, la configuration et les concepts essentiels pour intégrer ce produit.
