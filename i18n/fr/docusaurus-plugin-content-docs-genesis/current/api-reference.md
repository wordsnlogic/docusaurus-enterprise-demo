# Référence API

## Authentification

Toutes les requêtes vers l'API Genesis doivent inclure un jeton porteur valide dans l'en-tête Authorization.

## Points de terminaison

Le tableau ci-dessous liste les principaux points de terminaison exposés par l'API Genesis.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/genesis/users` | Create a user |
| POST | `/v1/genesis/sessions` | Start an authenticated session |
| POST | `/v1/genesis/sso/connections` | Configure an enterprise SSO connection |

## Assistance
