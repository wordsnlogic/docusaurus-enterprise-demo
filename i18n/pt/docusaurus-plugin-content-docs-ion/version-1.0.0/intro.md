# Introdução

Bem-vindo à documentação do Ion.

Ion é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- 135+ currencies and local payment methods
- PCI-DSS Level 1 compliant card vaulting
- Usage-based and subscription billing

Esta seção aborda instalação, configuração e os principais conceitos para integrar com este produto.
