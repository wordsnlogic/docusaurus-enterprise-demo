# Referência da API

## Autenticação

Todas as requisições à API do Ion devem incluir um token bearer válido no cabeçalho Authorization.

## Endpoints

A tabela abaixo lista os principais endpoints expostos pela API do Ion.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/ion/charges` | Create a one-time charge |
| POST | `/v1/ion/subscriptions` | Create a subscription |
| POST | `/v1/ion/refunds` | Issue a refund |

## Suporte

Para dúvidas sobre o Ion, entre em contato com a equipe de produto ou visite o fórum da comunidade.
