# Referência da API

## Autenticação

Todas as requisições à API do Echo devem incluir um token bearer válido no cabeçalho Authorization.

## Endpoints

A tabela abaixo lista os principais endpoints expostos pela API do Echo.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/echo/status` | Health/status check |
| GET | `/v1/echo/resources` | List resources |
| POST | `/v1/echo/resources` | Create a resource |
| DELETE | `/v1/echo/resources/:id` | Delete a resource |

## Suporte

Para dúvidas sobre o Echo, entre em contato com a equipe de produto ou visite o fórum da comunidade.
