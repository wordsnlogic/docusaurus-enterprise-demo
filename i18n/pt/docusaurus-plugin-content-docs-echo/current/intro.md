# Introdução

Bem-vindo à documentação do Echo.

Echo é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- Drop-in chat UI components for web and mobile
- End-to-end encrypted channels
- Webhooks for every message and presence event

Esta seção aborda instalação, configuração e os principais conceitos para integrar com este produto.
