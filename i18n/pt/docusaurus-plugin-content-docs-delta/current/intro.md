# Introdução

Bem-vindo à documentação do Delta.

Delta é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- Bi-directional sync with conflict resolution
- Sub-second propagation between endpoints
- Change-data-capture from Postgres, MySQL, and Mongo

## O que você vai encontrar aqui

Esta seção aborda instalação, configuração e os principais conceitos para integrar com este produto.
