# Introdução

Bem-vindo à documentação do Falcon.

Falcon é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- Hybrid keyword + vector ranking
- Typo-tolerant fuzzy matching
- Sub-100ms query latency at 10M+ documents
