# Introdução

Bem-vindo à documentação do Juno.

Juno é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- Cron and event-triggered jobs
- At-least-once and exactly-once delivery modes
- Automatic retries with exponential backoff

## O que você vai encontrar aqui

Esta seção aborda instalação, configuração e os principais conceitos para integrar com este produto.
