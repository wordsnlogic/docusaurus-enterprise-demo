# Referência da API

## Autenticação

Todas as requisições à API do Atlas devem incluir um token bearer válido no cabeçalho Authorization.

## Endpoints

A tabela abaixo lista os principais endpoints expostos pela API do Atlas.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/atlas/events` | Ingest a batch of analytics events |
| GET | `/v1/atlas/funnels/:id` | Retrieve funnel conversion data |
| GET | `/v1/atlas/cohorts/:id` | Retrieve a retention cohort |

## Suporte
