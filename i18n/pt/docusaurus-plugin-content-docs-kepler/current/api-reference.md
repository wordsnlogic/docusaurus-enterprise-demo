# Referência da API

## Autenticação

Todas as requisições à API do Kepler devem incluir um token bearer válido no cabeçalho Authorization.

## Endpoints

A tabela abaixo lista os principais endpoints expostos pela API do Kepler.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/kepler/geocode` | Convert an address to coordinates |
| POST | `/v1/kepler/routes` | Calculate a route between points |
| POST | `/v1/kepler/geofences` | Create a geofence |
