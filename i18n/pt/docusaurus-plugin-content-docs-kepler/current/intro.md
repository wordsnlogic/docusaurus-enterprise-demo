# Introdução

Bem-vindo à documentação do Kepler.

Kepler é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- Turn-by-turn routing and ETAs
- Reverse geocoding at street-level accuracy
- Geofencing with real-time enter/exit events

Esta seção aborda instalação, configuração e os principais conceitos para integrar com este produto.
