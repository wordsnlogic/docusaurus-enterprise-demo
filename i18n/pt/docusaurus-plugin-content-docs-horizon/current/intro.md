# Introdução

Bem-vindo à documentação do Horizon.

Horizon é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- Drag-and-drop dashboard builder
- Row-level data security per embed
- White-labeled embeds via signed tokens
