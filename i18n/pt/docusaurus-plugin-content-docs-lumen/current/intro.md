# Introdução

Bem-vindo à documentação do Lumen.

Lumen é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- Multi-channel delivery from one API
- Built-in deliverability and bounce handling
- Template management with versioning
