# Referência da API

## Autenticação

Todas as requisições à API do Lumen devem incluir um token bearer válido no cabeçalho Authorization.

## Endpoints

A tabela abaixo lista os principais endpoints expostos pela API do Lumen.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/lumen/messages` | Send a transactional message |
| GET | `/v1/lumen/messages/:id` | Check delivery status |
| POST | `/v1/lumen/templates` | Create a message template |

## Suporte

Para dúvidas sobre o Lumen, entre em contato com a equipe de produto ou visite o fórum da comunidade.
