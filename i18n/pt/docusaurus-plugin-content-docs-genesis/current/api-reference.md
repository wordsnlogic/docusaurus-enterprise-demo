# Referência da API

## Autenticação

Todas as requisições à API do Genesis devem incluir um token bearer válido no cabeçalho Authorization.

## Endpoints

A tabela abaixo lista os principais endpoints expostos pela API do Genesis.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/genesis/status` | Health/status check |
| GET | `/v1/genesis/resources` | List resources |
| POST | `/v1/genesis/resources` | Create a resource |
| DELETE | `/v1/genesis/resources/:id` | Delete a resource |
