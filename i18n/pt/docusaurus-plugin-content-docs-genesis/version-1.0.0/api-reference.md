# Referência da API

## Autenticação

Todas as requisições à API do Genesis devem incluir um token bearer válido no cabeçalho Authorization.

## Endpoints

A tabela abaixo lista os principais endpoints expostos pela API do Genesis.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/genesis/users` | Create a user |
| POST | `/v1/genesis/sessions` | Start an authenticated session |
| POST | `/v1/genesis/sso/connections` | Configure an enterprise SSO connection |

## Suporte

Para dúvidas sobre o Genesis, entre em contato com a equipe de produto ou visite o fórum da comunidade.
