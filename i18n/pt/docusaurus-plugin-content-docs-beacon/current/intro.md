# Introdução

Bem-vindo à documentação do Beacon.

Beacon é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- Multi-region synthetic checks every 30 seconds
- Alert routing to Slack, PagerDuty, and email
- Public, brandable status pages per customer

## O que você vai encontrar aqui

Esta seção aborda instalação, configuração e os principais conceitos para integrar com este produto.
