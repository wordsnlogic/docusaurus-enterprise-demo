# Referência da API

## Autenticação

Todas as requisições à API do Beacon devem incluir um token bearer válido no cabeçalho Authorization.

## Endpoints

A tabela abaixo lista os principais endpoints expostos pela API do Beacon.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/beacon/monitors` | Create a new uptime monitor |
| GET | `/v1/beacon/incidents` | List open and resolved incidents |
| POST | `/v1/beacon/status-pages` | Publish a public status page |

## Suporte

Para dúvidas sobre o Beacon, entre em contato com a equipe de produto ou visite o fórum da comunidade.
