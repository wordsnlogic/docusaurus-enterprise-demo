# Introdução

Bem-vindo à documentação do Cascade.

Cascade é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- Declarative pipeline definitions in YAML
- Built-in connectors for 40+ data sources
- Automatic schema drift detection

Esta seção aborda instalação, configuração e os principais conceitos para integrar com este produto.
