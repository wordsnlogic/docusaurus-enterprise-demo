# Introdução

Bem-vindo à documentação do Orion.

Orion é uma das linhas de produtos da plataforma Northwind Cloud.

## Principais recursos

- Global edge caching with instant invalidation
- Automatic image resizing and format negotiation
- S3-compatible API

Esta seção aborda instalação, configuração e os principais conceitos para integrar com este produto.
