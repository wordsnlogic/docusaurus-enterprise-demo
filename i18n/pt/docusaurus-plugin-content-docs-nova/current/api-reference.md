# Referência da API

## Autenticação

Todas as requisições à API do Nova devem incluir um token bearer válido no cabeçalho Authorization.

## Endpoints

A tabela abaixo lista os principais endpoints expostos pela API do Nova.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/nova/status` | Health/status check |
| GET | `/v1/nova/resources` | List resources |
| POST | `/v1/nova/resources` | Create a resource |
| DELETE | `/v1/nova/resources/:id` | Delete a resource |

## Suporte
