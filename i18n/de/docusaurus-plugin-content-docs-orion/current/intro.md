# Einführung

Willkommen in der Orion-Dokumentation.

Orion ist eine der Produktlinien der Northwind-Cloud-Plattform.

## Hauptfunktionen

- Global edge caching with instant invalidation
- Automatic image resizing and format negotiation
- S3-compatible API
