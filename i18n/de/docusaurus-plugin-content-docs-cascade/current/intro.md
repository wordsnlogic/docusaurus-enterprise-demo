Willkommen in der Cascade-Dokumentation.

Cascade ist eine der Produktlinien der Northwind-Cloud-Plattform.

## Hauptfunktionen

- Declarative pipeline definitions in YAML
- Built-in connectors for 40+ data sources
- Automatic schema drift detection
