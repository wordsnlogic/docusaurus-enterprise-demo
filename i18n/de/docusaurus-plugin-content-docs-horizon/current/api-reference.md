# API-Referenz

## Authentifizierung

Alle Anfragen an die Horizon-API müssen ein gültiges Bearer-Token im Authorization-Header enthalten.

## Endpunkte

Die folgende Tabelle listet die wichtigsten Endpunkte der Horizon-API auf.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/horizon/dashboards` | Create a dashboard |
| GET | `/v1/horizon/dashboards/:id/embed-token` | Generate a signed embed token |
| GET | `/v1/horizon/datasets` | List connected datasets |

## Support

Bei Fragen zu Horizon wenden Sie sich an das Produktteam oder besuchen Sie das Community-Forum.
