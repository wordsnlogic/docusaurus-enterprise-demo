# API-Referenz

## Authentifizierung

Alle Anfragen an die Lumen-API müssen ein gültiges Bearer-Token im Authorization-Header enthalten.

## Endpunkte

Die folgende Tabelle listet die wichtigsten Endpunkte der Lumen-API auf.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/lumen/messages` | Send a transactional message |
| GET | `/v1/lumen/messages/:id` | Check delivery status |
| POST | `/v1/lumen/templates` | Create a message template |

## Support

Bei Fragen zu Lumen wenden Sie sich an das Produktteam oder besuchen Sie das Community-Forum.
