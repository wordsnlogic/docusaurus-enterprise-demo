# API-Referenz

## Authentifizierung

Alle Anfragen an die Echo-API müssen ein gültiges Bearer-Token im Authorization-Header enthalten.

## Endpunkte

Die folgende Tabelle listet die wichtigsten Endpunkte der Echo-API auf.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/echo/channels` | Create a chat channel |
| POST | `/v1/echo/messages` | Send a message to a channel |
| GET | `/v1/echo/channels/:id/messages` | Fetch channel message history |

## Support

Bei Fragen zu Echo wenden Sie sich an das Produktteam oder besuchen Sie das Community-Forum.
