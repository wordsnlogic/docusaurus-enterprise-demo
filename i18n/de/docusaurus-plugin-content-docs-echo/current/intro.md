# Einführung

Willkommen in der Echo-Dokumentation.

Echo ist eine der Produktlinien der Northwind-Cloud-Plattform.

## Hauptfunktionen

- Drop-in chat UI components for web and mobile
- End-to-end encrypted channels
- Webhooks for every message and presence event
