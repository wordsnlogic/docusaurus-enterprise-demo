# API-Referenz

## Authentifizierung

Alle Anfragen an die Atlas-API müssen ein gültiges Bearer-Token im Authorization-Header enthalten.

## Endpunkte

Die folgende Tabelle listet die wichtigsten Endpunkte der Atlas-API auf.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/atlas/events` | Ingest a batch of analytics events |
| GET | `/v1/atlas/funnels/:id` | Retrieve funnel conversion data |
| GET | `/v1/atlas/cohorts/:id` | Retrieve a retention cohort |

## Support

Bei Fragen zu Atlas wenden Sie sich an das Produktteam oder besuchen Sie das Community-Forum.
