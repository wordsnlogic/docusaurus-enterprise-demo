# API-Referenz

## Authentifizierung

Alle Anfragen an die Kepler-API müssen ein gültiges Bearer-Token im Authorization-Header enthalten.

## Endpunkte

Die folgende Tabelle listet die wichtigsten Endpunkte der Kepler-API auf.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/kepler/status` | Health/status check |
| GET | `/v1/kepler/resources` | List resources |
| POST | `/v1/kepler/resources` | Create a resource |
| DELETE | `/v1/kepler/resources/:id` | Delete a resource |

## Support

Bei Fragen zu Kepler wenden Sie sich an das Produktteam oder besuchen Sie das Community-Forum.
