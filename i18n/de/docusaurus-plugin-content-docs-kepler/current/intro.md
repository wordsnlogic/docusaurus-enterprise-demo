# Einführung

Willkommen in der Kepler-Dokumentation.

Kepler ist eine der Produktlinien der Northwind-Cloud-Plattform.

## Hauptfunktionen

- Turn-by-turn routing and ETAs
- Reverse geocoding at street-level accuracy
- Geofencing with real-time enter/exit events
