# API-Referenz

## Authentifizierung

Alle Anfragen an die Ion-API müssen ein gültiges Bearer-Token im Authorization-Header enthalten.

## Endpunkte

Die folgende Tabelle listet die wichtigsten Endpunkte der Ion-API auf.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/ion/charges` | Create a one-time charge |
| POST | `/v1/ion/subscriptions` | Create a subscription |
| POST | `/v1/ion/refunds` | Issue a refund |

## Support

Bei Fragen zu Ion wenden Sie sich an das Produktteam oder besuchen Sie das Community-Forum.
