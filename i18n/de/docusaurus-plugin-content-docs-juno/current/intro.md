# Einführung

Willkommen in der Juno-Dokumentation.

Juno ist eine der Produktlinien der Northwind-Cloud-Plattform.

## Hauptfunktionen

- Cron and event-triggered jobs
- At-least-once and exactly-once delivery modes
- Automatic retries with exponential backoff

Dieser Abschnitt behandelt Installation, Konfiguration und die wichtigsten Konzepte für die Integration mit diesem Produkt.
