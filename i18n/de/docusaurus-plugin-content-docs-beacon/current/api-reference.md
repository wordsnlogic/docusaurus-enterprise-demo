# API-Referenz

## Authentifizierung

Alle Anfragen an die Beacon-API müssen ein gültiges Bearer-Token im Authorization-Header enthalten.

## Endpunkte

Die folgende Tabelle listet die wichtigsten Endpunkte der Beacon-API auf.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/beacon/monitors` | Create a new uptime monitor |
| GET | `/v1/beacon/incidents` | List open and resolved incidents |
| POST | `/v1/beacon/status-pages` | Publish a public status page |

## Support

Bei Fragen zu Beacon wenden Sie sich an das Produktteam oder besuchen Sie das Community-Forum.
