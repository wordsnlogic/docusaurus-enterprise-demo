# Introduzione

Benvenuto nella documentazione di Juno.

Juno è una delle linee di prodotto della piattaforma Northwind Cloud.

## Caratteristiche principali

- Cron and event-triggered jobs
- At-least-once and exactly-once delivery modes
- Automatic retries with exponential backoff
