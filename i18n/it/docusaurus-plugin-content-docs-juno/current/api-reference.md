# Riferimento API

## Autenticazione

Tutte le richieste all'API di Juno devono includere un token bearer valido nell'header Authorization.

## Endpoint

La tabella seguente elenca i principali endpoint esposti dall'API di Juno.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/juno/status` | Health/status check |
| GET | `/v1/juno/resources` | List resources |
| POST | `/v1/juno/resources` | Create a resource |
| DELETE | `/v1/juno/resources/:id` | Delete a resource |
