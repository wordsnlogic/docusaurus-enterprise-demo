# Introduzione

Benvenuto nella documentazione di Meridian.

Meridian è una delle linee di prodotto della piattaforma Northwind Cloud.

## Caratteristiche principali

- Visual workflow builder with branching logic
- 200+ pre-built integration steps
- Human-in-the-loop approval steps
