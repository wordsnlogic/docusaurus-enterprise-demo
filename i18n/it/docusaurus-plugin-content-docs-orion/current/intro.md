# Introduzione

Benvenuto nella documentazione di Orion.

Orion è una delle linee di prodotto della piattaforma Northwind Cloud.

## Caratteristiche principali

- Global edge caching with instant invalidation
- Automatic image resizing and format negotiation
- S3-compatible API
