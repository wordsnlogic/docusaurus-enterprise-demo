# Introduzione

Benvenuto nella documentazione di Falcon.

Falcon è una delle linee di prodotto della piattaforma Northwind Cloud.

## Caratteristiche principali

- Hybrid keyword + vector ranking
- Typo-tolerant fuzzy matching
- Sub-100ms query latency at 10M+ documents
