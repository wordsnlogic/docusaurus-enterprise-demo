# Riferimento API

## Autenticazione

Tutte le richieste all'API di Beacon devono includere un token bearer valido nell'header Authorization.

## Endpoint

La tabella seguente elenca i principali endpoint esposti dall'API di Beacon.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/beacon/monitors` | Create a new uptime monitor |
| GET | `/v1/beacon/incidents` | List open and resolved incidents |
| POST | `/v1/beacon/status-pages` | Publish a public status page |
