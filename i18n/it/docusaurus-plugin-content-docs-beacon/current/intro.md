# Introduzione

Benvenuto nella documentazione di Beacon.

Beacon è una delle linee di prodotto della piattaforma Northwind Cloud.

## Caratteristiche principali

- Multi-region synthetic checks every 30 seconds
- Alert routing to Slack, PagerDuty, and email
- Public, brandable status pages per customer
