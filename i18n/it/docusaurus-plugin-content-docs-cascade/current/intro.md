# Introduzione

Benvenuto nella documentazione di Cascade.

Cascade è una delle linee di prodotto della piattaforma Northwind Cloud.

## Caratteristiche principali

- Declarative pipeline definitions in YAML
- Built-in connectors for 40+ data sources
- Automatic schema drift detection
