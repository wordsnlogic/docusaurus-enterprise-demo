# Introduzione

Benvenuto nella documentazione di Ion.

Ion è una delle linee di prodotto della piattaforma Northwind Cloud.

## Caratteristiche principali

- 135+ currencies and local payment methods
- PCI-DSS Level 1 compliant card vaulting
- Usage-based and subscription billing
