# Introduzione

Benvenuto nella documentazione di Kepler.

Kepler è una delle linee di prodotto della piattaforma Northwind Cloud.

## Caratteristiche principali

- Turn-by-turn routing and ETAs
- Reverse geocoding at street-level accuracy
- Geofencing with real-time enter/exit events
