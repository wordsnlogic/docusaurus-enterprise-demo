# Riferimento API

## Autenticazione

Tutte le richieste all'API di Kepler devono includere un token bearer valido nell'header Authorization.

## Endpoint

La tabella seguente elenca i principali endpoint esposti dall'API di Kepler.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/kepler/geocode` | Convert an address to coordinates |
| POST | `/v1/kepler/routes` | Calculate a route between points |
| POST | `/v1/kepler/geofences` | Create a geofence |

## Supporto
