# Introduzione

Benvenuto nella documentazione di Delta.

Delta è una delle linee di prodotto della piattaforma Northwind Cloud.

## Caratteristiche principali

- Bi-directional sync with conflict resolution
- Sub-second propagation between endpoints
- Change-data-capture from Postgres, MySQL, and Mongo
