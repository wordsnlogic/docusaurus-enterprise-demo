# Introduction

Welcome to the Atlas documentation.

Atlas is one of the product lines in the Northwind Cloud platform. Product analytics and event tracking.

## Key features

- Real-time event streaming with sub-second ingestion
- Custom funnels and retention cohorts
- SQL-based ad-hoc querying over raw event data

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
