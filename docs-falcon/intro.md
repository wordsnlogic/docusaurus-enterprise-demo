# Introduction

Welcome to the Falcon documentation.

Falcon is one of the product lines in the Northwind Cloud platform. Hosted full-text and vector search.

## Key features

- Hybrid keyword + vector ranking
- Typo-tolerant fuzzy matching
- Sub-100ms query latency at 10M+ documents

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
