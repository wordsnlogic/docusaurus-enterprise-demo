# Introduction

Welcome to the Horizon documentation.

Horizon is one of the product lines in the Northwind Cloud platform. Embeddable dashboards and BI.

## Key features

- Drag-and-drop dashboard builder
- Row-level data security per embed
- White-labeled embeds via signed tokens

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
