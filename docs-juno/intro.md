# Introduction

Welcome to the Juno documentation.

Juno is one of the product lines in the Northwind Cloud platform. Distributed job scheduling.

## Key features

- Cron and event-triggered jobs
- At-least-once and exactly-once delivery modes
- Automatic retries with exponential backoff

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
