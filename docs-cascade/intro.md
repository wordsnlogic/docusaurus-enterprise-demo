# Introduction

Welcome to the Cascade documentation.

Cascade is one of the product lines in the Northwind Cloud platform. Managed data pipelines and ETL.

## Key features

- Declarative pipeline definitions in YAML
- Built-in connectors for 40+ data sources
- Automatic schema drift detection

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
