# Introduction

Welcome to the Nova documentation.

Nova is one of the product lines in the Northwind Cloud platform. Managed ML model hosting.

## Key features

- One-command deploy from common ML frameworks
- Auto-scaling GPU inference endpoints
- Built-in request/response logging for drift detection

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
