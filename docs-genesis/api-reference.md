# API Reference

## Authentication

All requests to the Genesis API must include a valid bearer token in the Authorization header.

## Endpoints

The table below lists the primary endpoints exposed by the Genesis API.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/genesis/users` | Create a user |
| POST | `/v1/genesis/sessions` | Start an authenticated session |
| POST | `/v1/genesis/sso/connections` | Configure an enterprise SSO connection |
