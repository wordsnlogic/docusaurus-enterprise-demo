# Introduction

Welcome to the Echo documentation.

Echo is one of the product lines in the Northwind Cloud platform. Programmable chat and messaging API.

## Key features

- Drop-in chat UI components for web and mobile
- End-to-end encrypted channels
- Webhooks for every message and presence event

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
