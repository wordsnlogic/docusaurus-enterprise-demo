# Introduction

Welcome to the Genesis documentation.

Genesis is one of the product lines in the Northwind Cloud platform. Identity, auth, and SSO platform.

## Key features

- SAML and OIDC SSO out of the box
- Passwordless magic-link and passkey login
- Fine-grained role-based access control

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
