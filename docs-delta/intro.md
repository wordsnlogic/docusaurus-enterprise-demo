# Introduction

Welcome to the Delta documentation.

Delta is one of the product lines in the Northwind Cloud platform. Real-time data sync across services.

## Key features

- Bi-directional sync with conflict resolution
- Sub-second propagation between endpoints
- Change-data-capture from Postgres, MySQL, and Mongo

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
