# API Reference

## Authentication

All requests to the Ion API must include a valid bearer token in the Authorization header.

## Endpoints

The table below lists the primary endpoints exposed by the Ion API.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/ion/status` | Health/status check |
| GET | `/v1/ion/resources` | List resources |
| POST | `/v1/ion/resources` | Create a resource |
| DELETE | `/v1/ion/resources/:id` | Delete a resource |
