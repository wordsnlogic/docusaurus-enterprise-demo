# Introduction

Welcome to the Lumen documentation.

Lumen is one of the product lines in the Northwind Cloud platform. Transactional email, SMS, and push.

## Key features

- Multi-channel delivery from one API
- Built-in deliverability and bounce handling
- Template management with versioning

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
