# API Reference

## Authentication

All requests to the Lumen API must include a valid bearer token in the Authorization header.

## Endpoints

The table below lists the primary endpoints exposed by the Lumen API.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/lumen/messages` | Send a transactional message |
| GET | `/v1/lumen/messages/:id` | Check delivery status |
| POST | `/v1/lumen/templates` | Create a message template |
