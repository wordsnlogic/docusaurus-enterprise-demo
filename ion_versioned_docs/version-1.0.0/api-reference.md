# API Reference

## Authentication

All requests to the Ion API must include a valid bearer token in the Authorization header.

## Endpoints

The table below lists the primary endpoints exposed by the Ion API.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/ion/charges` | Create a one-time charge |
| POST | `/v1/ion/subscriptions` | Create a subscription |
| POST | `/v1/ion/refunds` | Issue a refund |
