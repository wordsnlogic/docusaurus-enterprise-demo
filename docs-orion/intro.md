# Introduction

Welcome to the Orion documentation.

Orion is one of the product lines in the Northwind Cloud platform. Object storage and CDN.

## Key features

- Global edge caching with instant invalidation
- Automatic image resizing and format negotiation
- S3-compatible API

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
