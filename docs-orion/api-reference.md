# API Reference

## Authentication

All requests to the Orion API must include a valid bearer token in the Authorization header.

## Endpoints

The table below lists the primary endpoints exposed by the Orion API.

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/orion/status` | Health/status check |
| GET | `/v1/orion/resources` | List resources |
| POST | `/v1/orion/resources` | Create a resource |
| DELETE | `/v1/orion/resources/:id` | Delete a resource |
