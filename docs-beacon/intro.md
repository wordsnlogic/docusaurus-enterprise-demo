# Introduction

Welcome to the Beacon documentation.

Beacon is one of the product lines in the Northwind Cloud platform. Uptime monitoring and alerting.

## Key features

- Multi-region synthetic checks every 30 seconds
- Alert routing to Slack, PagerDuty, and email
- Public, brandable status pages per customer

## What you'll find here

This section covers installation, configuration, and the core concepts you need to integrate with this product.
