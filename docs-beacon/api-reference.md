# API Reference

## Authentication

All requests to the Beacon API must include a valid bearer token in the Authorization header.

## Endpoints

The table below lists the primary endpoints exposed by the Beacon API.

| Method | Path | Description |
| --- | --- | --- |
| POST | `/v1/beacon/monitors` | Create a new uptime monitor |
| GET | `/v1/beacon/incidents` | List open and resolved incidents |
| POST | `/v1/beacon/status-pages` | Publish a public status page |
